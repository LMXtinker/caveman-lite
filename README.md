# caveman-lite

Minimal Claude plugin marketplace containing only the core `caveman` skill from
[JuliusBrussee/caveman](https://github.com/JuliusBrussee/caveman) (MIT).

A GitHub Action checks upstream daily and commits the latest release's SKILL.md.

Add in claude.ai: Customize → Plugins → + → Add marketplace → Add from a repository → this repo's URL.
